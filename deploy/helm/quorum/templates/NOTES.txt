Thank you for installing {{ .Chart.Name }} {{ .Chart.Version }}.

Your Quorum instance will be available at:
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
  https://{{ .host }}
{{- end }}
{{- else }}
  kubectl port-forward -n {{ .Release.Namespace }} \
    svc/{{ include "quorum.fullname" . }} 8080:80
  then visit http://localhost:8080
{{- end }}

First-time setup — create the initial admin account (run once):

  curl -s -X POST {{ (index .Values.ingress.hosts 0).host | default "http://localhost:8080" }}/api/v1/auth/bootstrap \
    -H 'Content-Type: application/json' \
    -d '{"email":"admin@example.com","password":"<strong-password>"}'

Generate a JWT secret:
  openssl rand -hex 32

Check pod status:
  kubectl get pods -n {{ .Release.Namespace }} -l {{ include "quorum.selectorLabels" . | replace "\n" "," }}
